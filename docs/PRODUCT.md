# Product

Delta Qoralis is planned as a human-controlled system that takes a potential business from discovery through service delivery:

Business discovery → Website analysis → Lead qualification → Contact discovery → Outreach draft → Human approval → Email → Replies → Client requirements → Website generation → Preview → Payment → Deployment → Support subscription.

The foundation is complete and Phase 1 has begun. The implementation defines a provider-independent discovery contract and a persistence boundary for audited, idempotent creation of normalized discovery candidates. It supports explicit, disabled-by-default Geoapify configuration and a bounded adapter that an approved caller can construct and invoke for one page using four exact business categories. There is still no discovery runner, multi-page orchestration, automatic persistence flow, or CLI, so discovery is not operational end to end. It also does not crawl websites, analyze or qualify leads, extract contacts, draft or send messages, process payments, deploy projects, or provide a dashboard.
