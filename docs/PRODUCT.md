# Product

Delta Qoralis is planned as a human-controlled system that takes a potential business from discovery through service delivery:

Business discovery → Website analysis → Lead qualification → Contact discovery → Outreach draft → Human approval → Email → Replies → Client requirements → Website generation → Preview → Payment → Deployment → Support subscription.

The foundation is complete and Phase 1 — Lead Discovery is complete. Phase 2 — Website Crawling is current and is not completed. The implementation defines a provider-independent discovery contract and a persistence boundary for audited, idempotent creation of normalized discovery candidates. It supports explicit, disabled-by-default Geoapify configuration and a bounded adapter for four exact business categories. `runBoundedDiscovery` orchestrates bounded pages for one injected provider and persists accepted outcomes. `npm run discover` is the controlled operator command that composes those pieces for one explicit human actor. Discovery is operational through that command. One safe page fetch also exists: every connection goes through DQ-006, the socket is pinned, and redirects are revalidated. One present lead website can become in-memory crawl evidence. There is no crawl command, no crawl persistence, no spider, no analysis, and no outreach. DQ-020 and DQ-021 are completed. DQ-022, DQ-023, and DQ-024 remain untitled and have not started. Phase 3 — Website Analysis remains planned. Lead qualification, contact discovery, messaging, payments, deployment, and a dashboard are not implemented.
